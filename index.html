Diccionario Git

Aprendiendo a trabajar con ramas

Una colección visual de los comandos esenciales de Git, pensada para consultar rápido y entender de un vistazo qué hace cada uno.

$ git --version referencia rápida
01

git init

Inicializa un nuevo repositorio local en la carpeta actual.

02

git clone

Descarga una copia exacta de un repositorio remoto.

03

git add

Prepara los cambios (staging) para ser incluidos en el próximo commit.

04

git commit

Guarda una captura de los cambbios preparados en el historial.
